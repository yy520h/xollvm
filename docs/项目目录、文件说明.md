# 项目目录、文件说明

## 根目录

| 路径 | 作用 |
| --- | --- |
| `VMPass.cpp` | VM 配置解析和 VM function pass 入口 |
| `VMPass_Impl.cpp` | VM prepare/commit 生命周期和 IR 规范化 |
| `VMPass_Plan.cpp` | 模块级候选收集、engine 分组、freeze、commit |
| `VMPass_Emitter.cpp` | LLVM IR 到 VM bytecode 的 emitter |
| `VMPass_Verifier.cpp` | bytecode 边界、opcode、operand 和 CALL 校验 |
| `VMPass_Dispatch.cpp` | 共享 VM engine、dispatch 和 engine state |
| `VMPass_Handlers.cpp` | opcode handler 生成 |
| `VMPass_Wrapper.cpp` | 函数 wrapper、参数加载和返回值提取 |
| `VMPass_AntiDebug.cpp` | VM timing、integrity 和 anti-debug 辅助逻辑 |
| `AntiDebug.cpp` | 独立 antidebug pass、同步检测和 dynamic monitor |
| `ObfuscationConfig.cpp` | annotation parser 和 pass 配置解析 |
| `ObfuscationPipeline.cpp` | pass 排序和 function pipeline |
| `ObfReport.cpp` | JSON 报告和 witness 输出 |
| `CMakeLists.txt` | Obfuscator、测试目标和源文件注册 |

## 头文件

| 路径 | 作用 |
| --- | --- |
| `include/llvm/Transforms/Obfuscator/VMPass_Impl.h` | VMImpl、VMCtx、共享状态声明 |
| `include/llvm/Transforms/Obfuscator/VMPass_Plan.h` | VMPlanCoordinator 和 prepared candidate |
| `include/llvm/Transforms/Obfuscator/VMPass_Requirements.h` | requirement set、engine key、witness |
| `include/llvm/Transforms/Obfuscator/VMPass_Emitter.h` | emitter 数据结构和需求记录 |
| `include/llvm/Transforms/Obfuscator/VMPass_ISA.h` | VM opcode、operand 和编码定义 |
| `include/llvm/Transforms/Obfuscator/ObfuscationConfig.h` | 各 pass 配置结构 |
| `include/llvm/Transforms/Obfuscator/ObfReport.h` | 报告结构和 JSON 接口 |
| `include/llvm/Transforms/Obfuscator/AntiDebug.h` | 独立 AntiDebugPass 声明 |

## 测试目录

| 路径 | 作用 |
| --- | --- |
| `utils/VMRequirementsTest.cpp` | C++ requirements、verifier、preparation、coordinator 测试 |
| `utils/obf_runtime_tests.py` | runtime case runner |
| `utils/cases/` | 测试 case 注册、程序模板和运行驱动 |
| `utils/gates/` | IR 结构 gate |
| `utils/programs/` | 测试程序模板 |

构建目录 `build/` 只保存中间产物和本地构建输出，不应作为源码文档或逻辑入口。
